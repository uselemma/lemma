The MCP server lets your coding agent call Lemma directly: list traces and issues, inspect evidence, and take the same authorized actions the API exposes, all without you switching to the dashboard. This isn't the same connection as [Inspect](/platform/inspect); Inspect runs in-product, while the MCP server is for editors and coding agents.

The endpoint is `https://api.uselemma.ai/mcp` (trailing slash variants work the same), authenticated with `Authorization: Bearer <organization API key>`. Pass a project ID on project-scoped tools. Lemma only records MCP activation for a project after a successful project-scoped tool call, so saving the URL in Cursor isn't activation by itself.

## Prerequisites

- A Lemma organization with at least one project that has, or will have, traces
- An organization API key from **API Keys** or the project get-started flow. Copy it immediately; Lemma won't show it again. Keep it server-side in your coding tool's MCP config, never in a public repo.
- An MCP client that supports Streamable HTTP, such as Cursor, Claude Desktop, or Claude Code

## Connect your coding agent

<Steps>
  <Step title="Get your API key">
    Create an organization API key in the [Lemma dashboard](https://platform.uselemma.ai).

    <Warning>
      Copy your key immediately after creating it. You won't be able to see it again.
    </Warning>
  </Step>
  <Step title="Add it to your IDE">
    <Tabs>
      <Tab title="Cursor">
        In **Settings > MCP Servers**, add:

        ```json
        {
          "mcpServers": {
            "lemma": {
              "url": "https://api.uselemma.ai/mcp",
              "headers": {
                "Authorization": "Bearer <your-api-key>"
              }
            }
          }
        }
        ```
      </Tab>
      <Tab title="Claude Desktop">
        Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

        ```json
        {
          "mcpServers": {
            "lemma": {
              "type": "http",
              "url": "https://api.uselemma.ai/mcp",
              "headers": {
                "Authorization": "Bearer <your-api-key>"
              }
            }
          }
        }
        ```

        Restart Claude Desktop after saving.
      </Tab>
      <Tab title="Claude Code">
        Run this in your terminal:

        ```bash
        claude mcp add --transport http lemma \
          https://api.uselemma.ai/mcp \
          --header "Authorization: Bearer <your-api-key>"
        ```
      </Tab>
      <Tab title="Other">
        Any MCP client that supports Streamable HTTP transport uses the same shape:

        ```json
        {
          "mcpServers": {
            "lemma": {
              "url": "https://api.uselemma.ai/mcp",
              "headers": {
                "Authorization": "Bearer <your-api-key>"
              }
            }
          }
        }
        ```
      </Tab>
    </Tabs>

    Replace `<your-api-key>` with the organization API key you copied.
  </Step>
  <Step title="Try it out">
    Ask your agent:

    ```
    Use Lemma to show me my last 5 traces, including any errors.
    ```

    Include the project ID if your client hasn't already selected one.
  </Step>
</Steps>

## What tools exist

REST and MCP share one operation list; see the [API Reference](/api-reference) for the full set. Results get truncated once they're oversized, so prefer pagination over asking for every span at once.

Typical uses include pulling the last traces with errors, inspecting a specific issue, exporting an issue as markdown, and creating or linking a Linear ticket when you're authorized to. MCP clients require confirmation before running any write tool.
